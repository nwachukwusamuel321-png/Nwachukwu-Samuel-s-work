# Ecommerce API

A simple Node.js ecommerce API built with Express. It provides endpoints for products, orders, and users.

## Getting started

1. Install dependencies

```bash
npm install
```

2. Start the server

```bash
npm start
```

3. API endpoints

- `GET /api/products`
- `GET /api/products/:id`
- `POST /api/products`
- `PUT /api/products/:id`
- `DELETE /api/products/:id`
- `GET /api/orders`
- `GET /api/orders/:id`
- `POST /api/orders`
- `GET /api/users`
- `GET /api/users/:id`
- `POST /api/users`

## Notes

This project uses in-memory storage for demonstration purposes. You can extend it with a database like MongoDB or PostgreSQL.
